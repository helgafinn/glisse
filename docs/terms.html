What you should know before installing

These are not disclaimers hidden in small print; they are the actual conditions of the software, and they are stated on the home page too.

  • It uses private Apple APIs. macOS exposes no public interface for setting screen brightness or for reading raw trackpad contacts, so the app resolves undocumented symbols at runtime. These can be changed or removed by Apple in any macOS update. When that happens the affected feature stops working; the app is written to degrade rather than crash, but the feature loss is real. Every such symbol is documented in the repository along with the reason no public alternative exists.
  • It is ad-hoc signed, not notarised. Notarisation requires a paid Apple Developer account this project does not have. This is why installation uses --no-quarantine, and why macOS forgets the Accessibility permission each time you upgrade. You are choosing to run software that Apple has not reviewed or vouched for.
  • It is not on the Mac App Store and cannot be. No entitlement exists for the capabilities it needs.
  • Some paths are unverified. External-monitor brightness over DDC, Intel Macs, and the standalone Magic Trackpad are implemented but have not been tested on that hardware.

Because the source is public, you are able to verify all of this yourself before running it, and building from source is a supported path.
