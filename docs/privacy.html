Privacy Policy

Glissé is a free, open-source macOS utility. It collects no data about you, and there is no server for it to collect data to.

The application

Glissé contains no network code of any kind. It makes no outbound connections, so it cannot send anything anywhere. There is no telemetry, no analytics, no crash reporting, no update check, no licence check, and no account system. Nothing about your usage is recorded or transmitted.

What the app reads on your Mac, and why:

  • Trackpad contact data, to detect an edge slide. It is used in the moment to compute a gesture and is never stored or written to disk.
  • Display and audio state, to read and set the current brightness and volume.
  • Keystroke timing, if Accessibility is granted, so gestures can be suppressed for half a second after you type. The event tap is created listen-only: it observes that a key was pressed in order to start a timer, and it cannot record, alter or block what you typed.
  • Modifier key state, if you enable the modifier requirement, through a second listen-only tap.

Your settings are stored locally in the standard macOS preferences domain xyz.glisse.Glisse, on your machine only. Removing the app and running defaults delete xyz.glisse.Glisse deletes them.

Because the app is open source under the MIT licence, none of the above has to be taken on trust. The source is public and can be read or built yourself.

This website

This site is static. It sets no cookies, embeds no third-party scripts, loads no external fonts, and runs no analytics or tracking of any kind. The brightness and volume you set by dragging the page edges are held in memory in your own browser for the length of the visit and are never transmitted or saved.

The site is hosted on GitHub Pages. As with any web host, GitHub receives the technical information required to serve a page — your IP address and browser user agent — and may retain it in its own server logs. That processing is GitHub's, not ours, and is covered by the GitHub Privacy Statement. We have no access to those logs.

Downloads are served from GitHub Releases, and the Homebrew formula fetches from the same place, so the same applies there.

Children

Glissé is a general-purpose utility and is not directed at children. Since no data is collected from anyone, none is collected from children either.

Changes

If this policy changes, the revision will be committed to the project repository, so the full history of what it said and when is public. The date at the top reflects the current version.

Contact

Questions about privacy, or anything else, belong in the project issue tracker, where the answer is public and useful to the next person who asks.
